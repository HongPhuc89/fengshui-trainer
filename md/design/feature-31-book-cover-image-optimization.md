# Technical Solution: Book Cover Image Optimization + Video Thumbnail Optimization

## Document Information
- **Feature**: Book Cover + Video Thumbnail WebP Optimization
- **Feature Number**: 31
- **Created**: 2026-04-14
- **Status**: Draft — Awaiting PO Review

---

## Summary

Add `small_cover` (`CharField`) to `Book` and `small_thumbnail` (`CharField`) to `VideoLesson`, both storing public Bunny CDN URLs for resized WebP versions. Original `cover_image` (Book, Supabase) and `thumbnail` (VideoLesson, Supabase) are untouched. A shared utility in `videos/bunny_file_storage.py` handles: existence check (skip if already on Bunny), Pillow resize + WebP conversion, and upload with long-lived CDN cache headers. Thin wrappers in `books/utils.py` and `videos/utils.py` call the shared utility with model-specific Bunny keys.

---

## Analysis

### Requirements / Constraints
- Original `cover_image` / `thumbnail` (Supabase `ImageField`) must not be modified.
- `small_cover`: max 400×600 px (portrait 2:3) — covers 140px HomeView card at 2× Retina + buffer.
- `small_thumbnail`: max 400×225 px (landscape 16:9) — covers 180px HomeView course card at 2× Retina + buffer.
- WebP quality 85 → target ≤ 50 KB per image.
- **Skip upload if file already exists on Bunny** (HEAD check) — idempotent, avoids redundant bandwidth.
- **Cache-Control headers** on upload → Bunny CDN caches at edge for 1 year.
- Store as plain `CharField` (CDN URL string) — no storage-backend plumbing, no Redis cache needed.
- No new packages — Pillow, `requests`, and Bunny Storage credentials already in stack.
- DB migrations required (2 new `CharField` fields).

### Out of Scope
- `VideoCourse.cover_image` — already a plain `CharField` storing an external URL (not an uploaded file). Cannot be processed.
- Mobile Flutter app — out of scope for now, API change is additive.

### Storage Architecture

| Model | Field | Backend | URL type |
|-------|-------|---------|----------|
| `Book` | `cover_image` | `LocalFirstSupabaseStorage` | Pre-signed Supabase URL |
| `Book` | `small_cover` *(new)* | Bunny Storage | Public CDN URL |
| `VideoLesson` | `thumbnail` | `LocalFirstSupabaseStorage` | Pre-signed Supabase URL |
| `VideoLesson` | `small_thumbnail` *(new)* | Bunny Storage | Public CDN URL |

### Layers Involved
- **Database**: `small_cover` on `books_book`, `small_thumbnail` on `videos_videolesson`.
- **Backend**: shared utility in `videos/bunny_file_storage.py`; thin wrappers in `books/utils.py` + `videos/utils.py`; `save()` hooks; serializers; 2 management commands.
- **Frontend**: listing cards switch to `small_cover` / `small_thumbnail`; fall back to originals if null (during backfill window).

### 2. Shared Utility — `upload_image_to_bunny()`

**`src/backend/videos/bunny_file_storage.py`** — extend existing file (already has `_storage_api_base`, `upload_pdf_to_bunny`, etc.)

```python
import io
import logging

from PIL import Image

logger = logging.getLogger(__name__)

_DEFAULT_WEBP_QUALITY = 85


def upload_image_to_bunny(
    source_image_field,
    storage_key: str,
    max_width: int,
    max_height: int,
    webp_quality: int = _DEFAULT_WEBP_QUALITY,
    skip_if_exists: bool = True,
) -> str:
    """
    Resize an ImageField to fit max_width × max_height, convert to WebP,
    and upload to Bunny Storage.

    Args:
        source_image_field: Django ImageField (must have .path accessible).
        storage_key: Bunny Storage key, e.g. 'book_covers/small/42.webp'.
        max_width: Bounding box width in px — caller passes the right value per asset type.
        max_height: Bounding box height in px — caller passes the right value per asset type.
        skip_if_exists: If True, HEAD-check Bunny first — skip upload if file exists.

    Returns:
        Public Bunny CDN URL for the file.

    Raises:
        requests.HTTPError: on Bunny upload failure.
    """
    import requests as http
    from django.conf import settings

    zone = settings.BUNNY_STORAGE_ZONE
    api_key = settings.BUNNY_STORAGE_API_KEY
    upload_url = f'{_storage_api_base()}/{zone}/{storage_key}'
    cdn_url = f'https://{settings.BUNNY_STORAGE_CDN_HOSTNAME}/{storage_key}'

    # 1. Existence check — skip upload if already on Bunny
    if skip_if_exists:
        check = http.head(upload_url, headers={'AccessKey': api_key}, timeout=10)
        if check.status_code == 200:
            logger.info('upload_image_to_bunny: already exists, skipping — %s', storage_key)
            return cdn_url

    # 2. Pillow resize + WebP conversion
    with Image.open(source_image_field.path) as img:
        img = img.convert('RGB')
        img.thumbnail((max_width, max_height), Image.LANCZOS)
        buf = io.BytesIO()
        img.save(buf, format='WEBP', quality=webp_quality, method=6)
        buf.seek(0)
        image_bytes = buf.read()

    # 3. Upload with long-lived CDN cache headers
    resp = http.put(
        upload_url,
        data=image_bytes,
        headers={
            'AccessKey': api_key,
            'Content-Type': 'image/webp',
            'Cache-Control': 'public, max-age=31536000',  # 1-year CDN edge cache
        },
        timeout=15,
    )
    resp.raise_for_status()

    logger.info('upload_image_to_bunny: uploaded — %s', cdn_url)
    return cdn_url
```

> **`skip_if_exists=True` by default** — makes both the `save()` hook and management command idempotent.
> Pass `skip_if_exists=False` when using `--force` in the management command to force re-upload.

> **`Cache-Control: public, max-age=31536000`** — sent as the origin response header. Bunny CDN reads this and caches the file at edge PoPs for 1 year. On overwrite (re-upload), Bunny automatically purges the edge cache for that key.

### 4. `Book.save()` Hook

**`src/backend/books/models.py`**

```python
def save(self, *args, **kwargs):
    old_cover_name = None
    if self.pk:
        try:
            old_cover_name = Book.objects.get(pk=self.pk).cover_image.name
        except Book.DoesNotExist:
            pass

    super().save(*args, **kwargs)

    cover_changed = (
        self.cover_image.name != old_cover_name if self.cover_image
        else old_cover_name is not None
    )
    if not cover_changed:
        return

    # cover_image cleared → also clear small_cover
    if not self.cover_image:
        if self.small_cover:
            Book.objects.filter(pk=self.pk).update(small_cover='')
            self.small_cover = ''
        return

    try:
        from books.utils import generate_and_upload_small_cover
        cdn_url = generate_and_upload_small_cover(self.pk, self.cover_image)
        Book.objects.filter(pk=self.pk).update(small_cover=cdn_url)
        self.small_cover = cdn_url
    except Exception:
        logger.exception('Book.save: generate_and_upload_small_cover failed (pk=%s)', self.pk)
```

### 8. Management Commands

**`src/backend/books/management/commands/generate_small_covers.py`**

```python
from django.core.management.base import BaseCommand
from books.models import Book
from books.utils import generate_and_upload_small_cover


class Command(BaseCommand):
    help = "Generate and upload small_cover WebP to Bunny for books missing it."

    def add_arguments(self, parser):
        parser.add_argument('--force', action='store_true',
                            help='Re-upload even if already exists on Bunny.')

    def handle(self, *args, **options):
        force = options['force']
        qs = Book.objects.exclude(cover_image='').exclude(cover_image__isnull=True)
        if not force:
            qs = qs.filter(small_cover='')
        total = qs.count()
        self.stdout.write(f'Processing {total} books...')
        done = errors = 0
        for book in qs.iterator():
            try:
                cdn_url = generate_and_upload_small_cover(book.pk, book.cover_image, force=force)
                Book.objects.filter(pk=book.pk).update(small_cover=cdn_url)
                self.stdout.write(self.style.SUCCESS(f'  [{book.pk}] {book.title} → {cdn_url}'))
                done += 1
            except Exception as exc:
                self.stderr.write(self.style.ERROR(f'  [{book.pk}] {book.title}: FAILED — {exc}'))
                errors += 1
        self.stdout.write(f'\nDone. generated={done}  errors={errors}')
```

## Trade-offs & Notes

| Concern | Detail |
|---------|--------|
| **Originals untouched** | `cover_image` and `thumbnail` (Supabase) never modified. Always available for rollback. |
| **Existence check (HEAD)** | Before each upload, a HEAD request checks if the key already exists on Bunny. 200 → skip; 404 → upload. Makes `save()` hook and management command fully idempotent. |
| **CDN cache (1 year)** | `Cache-Control: public, max-age=31536000` set at upload time. Bunny edge PoPs cache the file for 1 year. On key overwrite, Bunny auto-purges edge cache. |
| **Stale data on field clear** | If admin clears `cover_image` / `thumbnail`, `save()` hook also clears `small_cover` / `small_thumbnail` immediately. |
| **Shared utility** | `upload_image_to_bunny()` lives in `videos/bunny_file_storage.py` (already the Bunny helper file). Thin wrappers in `books/utils.py` and `videos/utils.py` keep app-specific key logic isolated. |
| **Image dimensions** | `small_cover`: 400×600 px (portrait, covers 140px card at 2× Retina). `small_thumbnail`: 400×225 px (16:9, covers 180px card at 2× Retina). `max_width/max_height` are required params on `upload_image_to_bunny()` — each caller specifies correct values per asset type. |
| **Timeout 15s** | Sufficient for ≤50 KB WebP. If Bunny times out, admin save succeeds, `small_cover`/`small_thumbnail` stays blank — backfilled via management command. |
| **`VideoCourse.cover_image`** | `CharField` storing external URL — not an uploaded file, out of scope. |
| **`VideoCourseListSerializer` fallback** | When course has no `cover_image`, serializer falls back to first lesson's `small_thumbnail` (preferred) then `thumbnail`. |
| **Migration safety** | Two new blank `CharField` fields. Zero downtime. |
| **API backward compatibility** | All existing fields unchanged. `small_cover` and `small_thumbnail` are additive. |
| **Rollback** | Set `small_cover = ''` / `small_thumbnail = ''` in DB. Originals on Supabase intact. |
